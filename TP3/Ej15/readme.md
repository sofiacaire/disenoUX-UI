Elegí un enfoque **mobile-first** porque la mayoría de los usuarios probablemente ingresen desde el celular. Por eso definí primero los estilos base pensados para pantallas chicas (una sola columna, sin sidebar) y luego, con `min-width`, fui agregando el sidebar y el grid de 2 columnas a medida que la pantalla tiene más espacio disponible. Esto prioriza la experiencia mobile como caso base, en vez de tratarla como una simplificación del diseño de escritorio.
